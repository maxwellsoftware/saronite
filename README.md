# Saronite

Аддон для **World of Warcraft 3.3.5a** (Whitemane Frostmourne). Выгружает экипировку, сумки, банк, таланты и профессии в строку для бота [Saronite](https://t.me/keywatcher_bot), а его ответ показывает в отдельном окне: лучший сетап из твоих вещей с камнями и чарами текущей фазы.

## Установка

1. Скачайте `Saronite-x.y.z.zip` со страницы **Releases** (не «Code → Download ZIP»: там папка называется иначе, и игра её не увидит).
2. Распакуйте папку `Saronite` в `World of Warcraft/Interface/AddOns/`.
3. Перезапустите игру и проверьте, что аддон включён в списке аддонов.

## Использование

**Клик по кнопке Saronite** в окне персонажа (C) собирает лучший сетап из твоих вещей и показывает его в отдельном окне:

- какую вещь надеть в каждый слот и где она лежит (сумка, банк);
- какие камни вставить и какие чары нанести — из доступных в текущей фазе Frostmourne (сейчас T7), иметь их не нужно;
- меткость и мастерство «было → стало», изменения подсвечены.

Расчёт идёт прямо в игре, по кусочку за кадр, и занимает меньше секунды. Для ферала и ДК в окне есть переключатель «Как танк / Как ДД».

Один раз откройте банк — аддон запомнит вещи оттуда.

**Правый клик** или `/sar` — окно экспорта и импорта:

- «Экспорт» — строка `!SAR:1!…` с твоим персонажем: её можно отправить согильдийцу;
- «Импорт» — вставь чужую строку экспорта, и аддон соберёт сетап для того персонажа;
- «Последний сетап» — открыть последний расчёт.

Команды: `/sar`, `/sar import`, `/sar bank` (когда банк сканировался последний раз). Кнопку в окне персонажа можно сдвинуть, перетащив её с зажатым Shift.

## Как считается сетап

- Вещи — только твои (надето, сумки, банк) и только те, что персонаж может надеть.
- Веса характеристик спека — из [wowsims](https://github.com/wowsims/wotlk); меткость и мастерство считаются вместе с талантами и до капа ценнее всего остального.
- Камни и чары — из BiS-списков фазы (Bistooltip, wowtbc.gg) с характеристиками и русскими названиями из Wowhead; учитываются бонусы гнёзд, условия мета-камня, уникальные камни, профессии и пряжка на пояс.
- Аксессуары не меняются: их сила в проках, которые веса не описывают.

Тот же алгоритм работает в боте [saronite-bot](https://github.com/maxwellsoftware/saronite-bot) (Go); тесты требуют, чтобы оба давали одинаковый ответ.

### Шрифт

Интерфейс использует **Expressway**, если он есть: из ElvUI или файл `Saronite/Media/Fonts/Expressway.ttf`. Положить его туда можно самому, но в репозиторий он не входит: лицензия Typodermic не разрешает распространять шрифт внутри программ. Без него используется PT Sans Narrow (SIL OFL, в комплекте). На русском клиенте локализованный текст всегда рисуется PT Sans Narrow — у Expressway может не быть кириллицы.

## Разработка

```
Saronite/   сам аддон (то, что попадает в архив)
Saronite/Data/     данные фазы и веса (генерируются saronite-bot/cmd/phasegen)
docs/              форматы строк экспорта и ответа бота
tests/             запуск аддона в gopher-lua (Lua 5.1) с заглушками WoW API;
                   сверка Lua-оптимизатора с Go-версией бота
```

```sh
cd tests
go test ./...          # проверки
go test ./... -update  # обновить эталонные строки в tests/testdata
```

Эталон `tests/testdata/export_v1.txt` используется в тестах бота как пример реальной строки.

Релиз: создайте тег `vX.Y.Z` — GitHub Actions соберёт архив и опубликует релиз.
