# FrostmourneGear

Аддон для **World of Warcraft 3.3.5a** (Whitemane Frostmourne). Собирает экипировку, сумки, банк, таланты, символы и профессии в одну строку для гир-бота гильдии в Telegram.

## Установка

1. Скачайте `FrostmourneGear-x.y.z.zip` со страницы **Releases** (не «Code → Download ZIP»: там папка называется иначе, и игра её не увидит).
2. Распакуйте папку `FrostmourneGear` в `World of Warcraft/Interface/AddOns/`.
3. Перезапустите игру и проверьте, что аддон включён в списке аддонов.

## Использование

1. Один раз откройте банк: аддон запомнит вещи из него.
2. Наберите `/fg` или нажмите **«Экспорт»** в окне персонажа (C).
3. Строка уже выделена — нажмите **Ctrl+C**.
4. Отправьте её боту в Telegram (`/gear`).

Снимайте экспорт **без временных баффов** (фласки, еда, баффы рейда): бот сверяет свой расчёт с цифрами из окна персонажа.

Команды: `/fg` — окно экспорта, `/fg bank` — когда банк сканировался последний раз. Кнопку в окне персонажа можно сдвинуть, перетащив её с зажатым Shift.

## Разработка

```
FrostmourneGear/   сам аддон (то, что попадает в архив)
docs/              формат строки экспорта — контракт с ботом
tests/             запуск аддона в gopher-lua (Lua 5.1) с заглушками WoW API
```

```sh
cd tests
go test ./...          # проверки
go test ./... -update  # обновить эталонные строки в tests/testdata
```

Эталон `tests/testdata/export_v1.txt` используется в тестах бота как пример реальной строки.

Релиз: создайте тег `vX.Y.Z` — GitHub Actions соберёт архив и опубликует релиз.
