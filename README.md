# Saronite

Аддон для **World of Warcraft 3.3.5a** (Whitemane Frostmourne). Выгружает экипировку, сумки, банк, таланты и профессии в строку для бота [Saronite](https://t.me/keywatcher_bot), а его ответ показывает в отдельном окне: лучший сетап из твоих вещей с камнями и чарами текущей фазы.

## Установка

1. Скачайте `Saronite-x.y.z.zip` со страницы **Releases** (не «Code → Download ZIP»: там папка называется иначе, и игра её не увидит).
2. Распакуйте папку `Saronite` в `World of Warcraft/Interface/AddOns/`.
3. Перезапустите игру и проверьте, что аддон включён в списке аддонов.

## Использование

1. Один раз откройте банк: аддон запомнит вещи из него.
2. Наберите `/sar` или нажмите **«Экспорт»** в окне персонажа (C).
3. Строка уже выделена — нажмите **Ctrl+C**.
4. Отправьте её боту в Telegram (`/gear`).

Команды: `/sar` — экспорт, `/sar import` — вставить ответ бота, `/sar bank` — когда банк сканировался последний раз. Кнопку в окне персонажа можно сдвинуть, перетащив её с зажатым Shift. «Последний сетап» открывает последний импортированный ответ.

### Шрифт

Интерфейс использует **Expressway**, если он есть: из ElvUI или файл `Saronite/Media/Fonts/Expressway.ttf`. Положить его туда можно самому, но в репозиторий он не входит: лицензия Typodermic не разрешает распространять шрифт внутри программ. Без него используется PT Sans Narrow (SIL OFL, в комплекте). На русском клиенте локализованный текст всегда рисуется PT Sans Narrow — у Expressway может не быть кириллицы.

## Разработка

```
Saronite/   сам аддон (то, что попадает в архив)
docs/              форматы строки экспорта и ответа бота — контракт с ботом
tests/             запуск аддона в gopher-lua (Lua 5.1) с заглушками WoW API
```

```sh
cd tests
go test ./...          # проверки
go test ./... -update  # обновить эталонные строки в tests/testdata
```

Эталон `tests/testdata/export_v1.txt` используется в тестах бота как пример реальной строки.

Релиз: создайте тег `vX.Y.Z` — GitHub Actions соберёт архив и опубликует релиз.
